# База компаний Москвы для холодных звонков

Скрипт собирает заведения и компании Москвы **с телефоном** из OpenStreetMap
(Overpass API, открытая лицензия) и сохраняет их в Excel.

## Запуск

```bash
pip install -r requirements.txt
python parse_moscow.py                 # 3000 записей -> moscow_leads.xlsx
python parse_moscow.py --limit 2000    # другое количество
```

## Что в файле

- **Сводка**: сколько записей в каждой категории и сколько из них без сайта.
- **Все**: общий список.
- **Отдельный лист на каждую категорию**: рестораны и кафе, красота и уход, медицина,
  спорт и фитнес, автобизнес, гостиницы, образование, бытовые услуги,
  компании и офисы, магазины, развлечения.

Колонки: название, категория, подкатегория, телефон (формат `+7 (495) 123-45-67`),
доп. телефоны, сайт, «есть сайт», email, адрес, часы работы, VK/Telegram,
ссылка на карте, **статус звонка** (выпадающий список) и комментарий.

## Как отбираются записи

- Только записи с корректным российским номером; дубли по номеру убираются.
- Крупные сети (Пятёрочка, Сбер, МТС и т.п.) и госучреждения исключены.
- Компании **без сайта** берутся в первую очередь и выделены зелёным: это
  самые тёплые лиды для IT-агентства. Отключить приоритет можно флагом `--any-site`.
- Категории набираются поровну, чтобы база не состояла из одних кафе.
